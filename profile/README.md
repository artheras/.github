# Arthera

We build practical AI tools for coding, research, and connected workflows.

**Aria Code** is our open-source AI workspace. It can work in a project, inspect and edit files, run commands and tests, and connect to local or cloud models. Finance and other domain tools are available when their data sources are configured.

[Website](https://arthera.finance) · [Aria Code releases](https://github.com/artherahq/aria-code/releases)
